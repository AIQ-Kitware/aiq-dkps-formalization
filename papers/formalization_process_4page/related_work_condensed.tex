\section{Related work and where to start}
\label{sec:related}

Semantic alignment now has several dedicated approaches.  Beyond Compilation
measures the gap between compilation and judged faithfulness; CriticLean trains
a semantic critic; BEq/BEq+ tests equivalence against a trusted formal
reference; and ShadowBench checks a target against auxiliary ``shadow''
statements in both directions
\citep{zhang2026beyondcompilation,peng2025criticlean,liu2025beq,poiroux2025reliable,han2026shadowbench}.
These are useful when the main question is whether one formal statement captures
an intended theorem.

Project-scale tools address different parts of the review burden.  EconCSLib
provides a paper-facing review dashboard with source statements, Lean statements,
LLM assistance, and human judgments \citep{garg2026econcs}.  Lean Atlas / Lean
Compass identifies the declarations whose semantics can affect a selected target,
reducing what a reviewer needs to read \citep{yanahama2026leanatlas}.
ATLAS / AutoformBot pairs source/formal browsing and dependency graphs with
automated faithfulness assessment \citep{rammal2026scale}.  LeanMarathon,
FormaTheoria, and LeanArchitect integrate target review, provenance, or
informal/formal synchronization into longer developments
\citep{zhang2026leanmarathon,nie2026formatheoria,zhu2026leanarchitect}.

For a new project, these systems are better starting points than rebuilding our
workflow from scratch.  Our tooling is useful here as a case study: it grew from
problems encountered during one formalization and ended up resembling several of
these independently developed systems.
