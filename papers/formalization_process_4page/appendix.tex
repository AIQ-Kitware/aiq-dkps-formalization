\section{Data and reproducibility}
\label{app:data}

The structured inputs for this paper live under \texttt{data/}.  The 21
first-person accounts were found by web search and citation chasing.  Each row
retains the public source URL, bibliography key, the observation used in this
paper, a qualification note, and the categorical fields used for the
descriptive counts.  The checked-in \texttt{notes/practitioner\_accounts.md}
renders these rows as per-account source records so each observation can be
checked against its public source.  A JSON schema documents the fields and
allowed values; \texttt{make sources} validates the schema, unique identifiers,
citation keys, and URLs and regenerates the source notes and paper macros.  The
monthly Lean-publication series and selected Git timeline are kept in separate
CSV files, and the Git rows are checked against repository history during the
build.  Representativeness of the account snapshot is unknown, so we make no
prevalence estimates from it.

\section{Semantic-review page}

\begin{figure}[H]
  \centering
  \includegraphics[width=\linewidth,trim=0 250 0 0,clip]{figures/semantic-alignment-sine-theta-row.png}
  \caption{The current review page for the single-angle sine-theta theorem.
  The source passage and inherited context appear at left, the claimed
  source-to-Lean correspondence in the middle, and compiler-derived Lean
  evidence at right.  The interface records a review judgment alongside
  mechanical evidence.  Source/statement identity and Lean compilation are
  mechanical checks; the mathematical correspondence remains a review judgment.}
  \label{fig:dashboard}
\end{figure}

The page makes the checked declaration easy to retrieve, but a reader learning
Lean may still need help understanding the vocabulary inside that declaration.
For example, the meaning of \texttt{ClosedOperator}, \texttt{IsSelfAdjoint},
coercions, and typeclass assumptions can be spread across project code and
Mathlib.  Lean Compass's theorem-centered semantic dependency view suggests a
useful direction for this interface: make those definitions inspectable from
the statement while keeping proof-only dependencies out of the way
\citep{yanahama2026leanatlas}.
