# Candidate worked examples

The auditable candidate list now lives in
[`SEMANTIC_ALIGNMENT_CANDIDATES.md`](SEMANTIC_ALIGNMENT_CANDIDATES.md).

That file is generated from pinned Git revisions by `scripts/build_semantic_alignment_candidates.py`
and includes verbatim Lean signatures, commit/path/line provenance, snippet
hashes, repair status, and short explanations.  Do not maintain a second
hand-copied candidate list here.
