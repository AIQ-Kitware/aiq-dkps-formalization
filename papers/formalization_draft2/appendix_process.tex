\section{Source coverage and formalization evidence}
\label{app:source-coverage}

For Davis--Kahan, the denominator used in the paper is
\FormalizationDKResultCount{} results: the four unnumbered Section~2 theorems and
every named theorem, proposition, lemma, and corollary established in the paper.
Definitions, examples, open questions, proof steps, and results attributed to
other sources are excluded.  Twenty-eight counted results are proved at the
scope stated in the source.  Proposition~4.4 remains in the denominator and is
formally refuted as printed, with a repaired result proved separately.

For YWS, the source audit contains \YWSCensusEntryCount{} entries spanning the
three theorem-level claims and the lemmas, equations, identities, examples,
conventions, and corrections used to verify them.  Of these,
\YWSCensusExplicitAdditionCount{} are explicitly marked additions beyond the
printed paper, and all \YWSCensusVerifiedCount{} entries resolve to declarations
in the default build.

\label{app:accounting}

\subsection{Accounting scope}

Commit coverage is computed from the primary formalization repository.  The
program-level token totals also include measured Tau Ceti foundations work that
was developed in a separate repository and used by this formalization.  The Git
history is pinned at \AccountingSnapshot{}, and manuscript-only commits are
excluded from the coverage denominator.

\subsection{Measurement coverage}

Exact commit-level instrumentation began on \InstrumentationSnapshot{};
\CommitsBeforeInstrumentation{} included commits precede that date.  Backfilled
harness transcripts recover some earlier usage.  The retained data therefore
contain exact commit-attributed measurements, measured session usage without a
one-to-one commit assignment, and periods with no recovered telemetry.

\subsection{Model-resolved tokens, pricing, and energy}

Each token-bearing row records ordinary input, cache writes, cache reads, and
output by model.  Historical API prices are applied after token accounting.
Using the dated public price inputs gives an API-equivalent list-price value of
\MeasuredApiEquivalentCost{} for the observed lower-bound usage; valuing every
recorded Anthropic cache write at the one-hour rate gives
\MeasuredApiEquivalentCostOneHour{}.

The energy calculation uses a versioned serving model with throughput, server
power, cache-work factors, per-turn overhead, and datacenter power usage
effectiveness \citep{crall2026llmresource}.  The operational boundary covers LLM
serving and excludes model training, embodied hardware, client devices, and
network energy.  The paper reports both the central serving-model value and a
separate per-token cross-check.

\subsection{Coverage proxies and project-scale extrapolation}

Exact telemetry covers \ExactMeasuredCommitCount{} of \HistoryCommitCount{}
primary-repository commits (\ExactMeasuredCommitShare{}).  Those commits account
for \ExactMeasuredLeanLineChurn{} of \TotalLeanLineChurn{} cumulative Lean-line
insertions and deletions (\ExactMeasuredLeanLineChurnShare{}).  The extrapolations
in \cref{tab:resource-extrapolation} divide the exact primary-repository token
subset by each fraction.  One weights commits equally; the other uses changed
Lean lines as a coarse text-volume proxy.  Both assume comparable token
intensity between observed and unobserved work under the selected denominator.
