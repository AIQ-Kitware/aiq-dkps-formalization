# Lean code font

JuliaMono Regular, vendored unchanged from
https://github.com/cormullion/juliamono at `0dfc749503778730d6af79183a17fcde668ae626`.
The accompanying SIL Open Font License permits redistribution.
This is a third-party source asset, not rendered output.

The Lean code renderer registers this font locally, so slide builds use the
same mathematical glyphs without requiring a system font installation.
`DKVIS_LEAN_FONT` can select another installed font.
