# Sine-theta players (standalone visual draft)

This is a programmatically generated mathematical schematic for the
Davis--Kahan sine-theta theorem. It is **not included in the paper** and does
not change the journal manuscript, its figure numbering, or its build process.

- `render.py` is the authoritative source. It uses only Python's standard
  library and writes semantic, editable SVG primitives with named groups.
- `sine_theta_players.svg` is the generated **text-based** vector drawing.
- The geometric slice uses the same numbers as Figure 1 in
  `papers/dk_formalization_journal/paper.tex` (sine-theta section).

Regenerate from the repository root:

```bash
python visualizations/figures/sine_theta_players/render.py
python visualizations/figures/sine_theta_players/render.py --check
```

The `--check` mode runs numerical assertions and parses the SVG; no LaTeX,
Manim, or renderer is required. SVG can be opened directly in a browser or
Inkscape.

## Typography

The figure uses **TeX Gyre Pagella** for prose and **STIXGeneral** for
mathematical labels, with conventional serif fallbacks. These are TeX-oriented
fonts available through common Linux packages (for example, `fonts-texgyre`
and `fonts-stix` on Debian/Ubuntu).

The SVG uses real text rather than outlining letters. Subscripts such as
`F_ex`, `F_0`, and `A_0`, and adjoints such as `F_1*`, are drawn with editable
SVG `<tspan>` elements and baseline shifts. The numerical geometry and labels
are generated by the same standard-library Python script. The fonts are
referenced by family name and **not bundled** in this repository or overlay;
a system without them may show fallback serif faces.

For an optional PNG preview, use Inkscape locally:

```bash
inkscape visualizations/figures/sine_theta_players/sine_theta_players.svg \
  --export-filename=/tmp/sine_theta_players.png --export-width=1800
```


## Which objects are which?

Let `E` be the ambient Hilbert space. `F`, `F_ex`, and `G` are *coordinate*
Hilbert spaces, not assumed to be literal subspaces of `E`:

| Symbol | Type / role |
| --- | --- |
| `E_0` | Isometry `F -> E` representing the trial subspace |
| `A_0` | Self-adjoint trial-coordinate operator on `F` |
| `F_0` | Isometry `F_ex -> E` representing the desired exact spectral subspace |
| `F_1` | Isometry `G -> E` representing its exact orthogonal complement |
| `Lambda_1` | Self-adjoint restriction of the ambient operator to complementary coordinates `G` |
| `P_ex` | `F_0 F_0*`, orthogonal projection onto the desired exact spectral subspace |
| `R` | `Ahat E_0 - E_0 A_0 : F -> E`, the trial intertwining residual |
| `S` | `(I - P_ex) E_0 : F -> E`, the rectangular complementary component |
| `X` | `F_1* E_0 : F -> G`, the same complementary component in `G` coordinates |
| `Theta_0` | Positive angle operator on `F`; `abs(S) = sin(Theta_0)` |
| `delta` | Certified spectral separation between `A_0` and `Lambda_1` (according to a theorem gap hypothesis) |
| `lambda_1` | A spectral value of `Lambda_1`; scalar in the pictured rank-one example |

The central type checks are

```text
S = F_1 X,
abs(S) = sin(Theta_0),
Lambda_1 X - X A_0 = F_1* R.
```

Under the theorem's spectral, domain, and ideal-membership hypotheses,
`delta * N(sin(Theta_0)) <= N(R)` for a normalized symmetric operator-ideal
norm `N`.

## Auditable two-dimensional example

The pictured slice fixes `E = R^2` and `F = F_ex = G = R`, with

```text
theta = 40 degrees
Ahat = diag(1.9, 0.7)
F_0(h) = (h, 0)
F_1(g) = (0, g)
v = (cos(theta), sin(theta))
E_0(t) = t * v
A_0(t) = rho * t, where rho = <v, Ahat*v>
Lambda_1(g) = 0.7 * g
```

The *exact* complementary block is on `G`, so its scalar eigenvalue
`lambda_1 = 0.7`. In this example,

```text
rho = 1.9*cos(theta)^2 + 0.7*sin(theta)^2
    = 1.4041889066...
delta = rho - lambda_1 = 0.7041889066...
X(t) = t * sin(theta)
S(t) = (0, t * sin(theta))
R(t) = t * ((1.9 - rho)*cos(theta), (0.7 - rho)*sin(theta))
F_1*R(t) = t * (0.7 - rho)*sin(theta)
(Lambda_1*X - X*A_0)(t) = t * (0.7 - rho)*sin(theta)
```

Thus `delta * sin(theta) = abs(F_1*R(1)) <= norm(R(1))`. The
Rayleigh-quotient choice makes `R(1)` perpendicular to `v`, a property
validated by the generator's numerical checks. The rectangular `S` has
positive modulus `sin(theta)` on `F`.

Here the *ambient* eigenvalue gap is `1.9 - 0.7 = 1.2`; it is **not**
the plotted `delta`, which compares the *trial* operator `A_0` to the
*unwanted exact* block `Lambda_1`.

## Reading the figure

1. Blue: trial coordinates and their embedding into `E`.
2. Green: the desired exact subspace and its coordinate frame.
3. Violet: the orthogonal exact complement and its coordinate frame.
4. Orange: the residual measuring failure of the trial intertwining relation.

The geometric panel is rank one, so `Theta_0` reduces to the scalar
angle `theta`. In the general theorem, `A_0` and `Lambda_1` may be
unbounded, the coordinates can be infinite-dimensional, and the gap
condition can take interval/exterior or ordered forms. Those domain and
spectral configurations are described in the manuscript rather than
encoded by the two-dimensional drawing.

To change the example, update the three model constants near the top of
`render.py`; the geometry and gap positions are computed from them. For a
non-ordered configuration, revise the spectral panel too: this panel is
specifically labeled as the ordered rank-one example.
