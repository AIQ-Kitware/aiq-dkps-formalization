# Reusable mathematical figure sources

These standalone SVG drawings adapt geometric **construction logic** from the existing Manim learning scenes, as recorded in each SVG `<desc>`. They do not claim to be frame captures.

The SVGs are editable, versioned learning assets; the HTML deck renderer embeds the entire SVG into each self-contained HTML deck. The optional PPTX exporter embeds the same SVG rather than substituting a textual placeholder. No Manim video render or new third-party assets are required at request time.

Figure labels are redundant with the accompanying mathematical slide prose. The diagram art is not TTS content.
