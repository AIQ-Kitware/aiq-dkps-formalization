Purpose
-------
- Record the deep Spectra capability and reuse survey.
- Establish a real Git-submodule collaboration workflow without copying source.
- Keep Mathlib APIs as direct imports, not misleading vendor snapshots.
- Stage, but do not prematurely enable, the Lake path dependency while the
  Lean 4.31 / 4.32 compatibility seam remains open.
- Make upstream PR work easy through upstream/fork remotes and named branches.
- Create or detect the authenticated user's fork without relying on unsupported
  `gh repo fork --remote=false` syntax.

bootstrap script deliberately performs the Git operation and stages the parent
repository changes.

Default dependency behavior
---------------------------
The overlay does not immediately add Spectra as a Lake requirement.  The
submodule's audited toolchain is Lean 4.31.0-rc1 while DKPS uses 4.32.0-rc1.
After compatibility work, enable the path dependency with:

  python3 scripts/enable_spectra_lake_dependency.py
  scripts/spectra_import_smoke.sh
