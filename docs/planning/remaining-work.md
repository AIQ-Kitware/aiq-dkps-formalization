# Remaining-work tracker - retired

The R-numbered Mathlib-readiness tracker is no longer a current work queue. The
Mathlib staging track and the multi-agent lane system it referenced are both
retired, and preserving a second mutable backlog here made status drift harder to
spot.

Current work is determined from:

- `AGENTS.md` for project policy;
- `ForTauCeti/README.md` and `dev/tauceti/README.md` for reusable-library work;
- `dev/davis-kahan-1970-full-source-census.json` and
  `dev/davis-kahan-1970-frontier-status.md` for Davis--Kahan source fidelity;
- the relevant paper library itself for paper-specific work.

The old R-track inventory remains in Git history. Planning documents that cite an
R-number should be read as historical design/provenance, not as an active task.
