# Tau Ceti adaptation and Spectra extraction - historical plan

This plan has finished and its operational body has been removed from the working
documentation.

The important end-state decisions are now in `AGENTS.md` and
`ForTauCeti/README.md`:

- `ForTauCeti` is the maintained reusable mathematics package;
- `ForMathlib` has been retired;
- Spectra is retired from the maintained dependency graph;
- `external/TauCeti` is a read-only provenance/build reference during ordinary
  work;
- the retired multi-agent lane workflow is not part of current development.

For current Tau Ceti work, start at `dev/tauceti/README.md` and the checked-in
roadmap/manifest data. For the completed migration history, use Git history and the
explicitly historical records under `dev/tauceti/` and `retired/`.
